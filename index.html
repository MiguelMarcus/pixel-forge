Mapas para o jogo

Mesmo tamanho e transparência do sprite. Os mapas usam PNG RGBA, sem reduzir as cores dos vetores.

Prévia pronta

Essa opção grava a iluminação na imagem. Para luz dinâmica no jogo, use cor base + normal map.

Como usar

Comece com cores chapadas. O mapa cria um relevo estimado; não remove sombras já pintadas na arte.

No Godot: Sprite2D → CanvasTexture → Diffuse com a cor base e Normal Map com o mapa gerado. Adicione uma Light2D e use filtro nearest.

A autossombra exibida aqui é uma simulação de altura. Sombras projetadas no cenário dependem do motor do jogo.
